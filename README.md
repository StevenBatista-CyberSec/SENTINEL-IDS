## 👋 ¿Qué es Sentinel IDS?

**Sentinel IDS v2.0** es una herramienta avanzada de seguridad diseñada para interceptar, analizar y alertar sobre el tráfico anómalo en tu infraestructura de red. Creada desde cero con Python, combina el análisis profundo de paquetes con alertas en tiempo real.

Ideal para:
- 🔍 **Detección temprana** de escaneos de puertos y reconocimiento.
- 🛡️ **Monitorización** de ataques de denegación de servicio (DoS).
- 💻 **Laboratorios de Hacking Ético** y simulaciones de Red Team/Blue Team.
- 📊 **Administración de redes** y auditorías de seguridad en entornos controlados.

> *"En ciberseguridad, ver el tráfico invisible es la primera línea de defensa. Sentinel ilumina la red."*
